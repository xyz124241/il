# ItemLock + Sense

Paper-Plugin mit Item-Sperre (Menue + Bestaetigung) und der **Sense** (Schwert + Axt + Mace).
Das Resourcepack (ACI-Kristalle + Sense-Textur) liegt im Ordner `resourcepack/`.

## Download
Unter **Releases** (rechts auf der Repo-Seite) liegen nach jedem Build:
- `ItemLock.jar` -> in `plugins/` legen, Server neustarten
- `ACI-Crystals-Sense-ResourcePack.zip` -> ersetzt das alte ACI-Pack

Die SHA-1 des Packs steht in der Release-Beschreibung.

## Befehle
- `/itemlock` (`/il`, `/sperre`): Menue zum Sperren/Freigeben (mit Bestaetigung)
- `/itemlock list`, `/itemlock reload`
- `/sense give [spieler]`

Sense-Rezept (formlos): Netherite-Axt + Netherite-Schwert + Mace + Nether Star
